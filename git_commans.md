Describe que hacen los siguientes comandos de git, escribe su descripcion al frente en una sola linea.

git status: Este comando se usa para obtener el estado actual del repositorio

git clone: Este comando se usa para descargar una copia exacta de un repositorio remoto en mi máquina local.

git pull: Este comando se usa para descargar e integrar los cambios del repositorio remoto a la rama local actual.

git checkout: Este comando se usa para cambiar de rama.

git log: Este comando se usa para mostrar el historial cronológico de commits realizados.

git branch: Este comando se usa para listar, crear o eliminar ramas dentro del repositorio.

git add: Este comando se usa para añadir los cambios de los archivos al área de preparación (staging area).

git commit: Este comando se usa para guardar los cambios.

git push: Este comando se usa para subir las confirmaciones de tu rama local al repositorio remoto

git merge: Este comando se usa para unir el historial de dos o más ramas en una sola
